# tools.xm1221.cn 卡片

给聚合站用的卡片文案。路径挂在 `tools.xm1221.cn` 下面。

- **标题**：Architectury 模组模板
- **说明**：生成 Fabric + Forge / NeoForge 双平台模组工程，可选 Kotlin、Modrinth 依赖与国内 Maven 镜像。
- **路径**：`/arch-template`
- **链接**：`https://tools.xm1221.cn/arch-template/`

聚合站把 `/arch-template` 指到本目录的 Cloudflare Worker（或自建 Node 服务）即可。页面和接口都在这个前缀下：页面是 `/arch-template/`，生成接口是 `/arch-template/api/generate`。
